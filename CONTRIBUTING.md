# Contributing to F-Layer

F-Layer uses the Fuzzy Technologies development workflow.

Before contributing:

1. read [AGENTS.md](AGENTS.md) and [DEVELOPMENT_PROTOCOL.md](DEVELOPMENT_PROTOCOL.md);
2. start normal work from `develop` in a dedicated `feature/*` or `fix/*` branch;
3. link the implementation to a GitHub Task;
4. add tests and evidence appropriate to the changed boundary;
5. open a pull request to `develop` using the repository template.

Do not commit credentials, private infrastructure identifiers, local absolute paths, or environment-specific secrets.

Architecture-impacting work requires the applicable ADR together with the implementation.
