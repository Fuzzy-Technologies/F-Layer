## Digest

F-Layer 1.0.0 is the first versioned infrastructure baseline: manage explicitly
owned Yandex Cloud stacks, prepare a secure SSH gateway, and inspect health through
bounded diagnostics. Configuration, recovery, and cleanup have deterministic
offline test evidence; live cloud deployment and guest readiness still require
operator validation.

## What's Changed

### Added

- Strict configuration and durable state tied to explicit stack ownership.
- Yandex Cloud inventory and six-resource create/status/destroy orchestration,
  including idempotency, recovery, rollback, and ownership-checked cleanup.
- A secure SSH gateway profile with explicit access rules and verified generated
  artifacts; no private key or personal infrastructure material is distributed.
- Status/check commands and opt-in, resource-bounded HTTP health/benchmark probes.
- English installed-wheel API documentation and safe master-only Pages publishing;
  Russian and Simplified Chinese clearly indicate unavailable translations.
- Offline CI, linked-Task completion, branch cleanup, and ADR 0014 documenting
  scoped release history and the Fuzzy Technologies changelog format.

## Validation

Build provenance is available with the [GitHub release](https://github.com/Fuzzy-Technologies/F-Layer/releases/tag/v1.0.0).

## Breaking Changes

None relative to a previous stable F-Layer release; this is the initial versioned
baseline. Ownership/state contracts apply from the first release.

## Try it from source

```bash
git clone https://github.com/Fuzzy-Technologies/F-Layer.git
cd F-Layer
git checkout v1.0.0
python -m pip install .
python -m flayer --help
python -m flayer check --format json
```

Python 3.11 or newer is required. Cloud mutations additionally need an explicitly
selected account, owned plan/state paths, and mutation consent; check the shipped
architecture guides before operating a real stack.

## Notes

- Cloud RUNNING does not establish guest SSH/tunnel readiness. Guest image and
  external service behavior must be validated in the operator's environment.
- PyPI upload is not performed. Install from the exact tag or attached wheel.
