## Digest

F-Layer 1.1.0 makes the infrastructure baseline easier to install and operate:
a typed Python package, an installed `flayer` command, and practical guides for
configuration, diagnostics, and the first owned gateway deployment. Release
artifacts now have repeatable build and ownership checks. This is an additive
release; its validation uses isolated resources and does not establish live
cloud readiness.

## What's Changed

### Added

- A PEP 561 typed distribution and `flayer` console command, with one canonical
  source for runtime, wheel, and source-archive versions.
- Repeated byte-identical wheel/source-archive builds, source-archive wheel rebuild
  parity, archive ownership checks, metadata/RECORD verification, and build evidence.
- CI previews of audited distributions and a separately guarded, owner-confirmed
  manual PyPI workflow. PyPI upload is not enabled or performed by this release.
- User guides for installation, provider configuration, CLI results, and the
  first gateway deployment with explicit ownership and mutation consent.

### Changed

- Adopt the FuzzyRoutines-style FL logo family and clearer documentation navigation.
- Align Markdown table columns for readable source and validate their formatting.
- Present exact stable-tag installation instructions, released console behavior,
  and the detailed changelog in both source archives and generated documentation.

### Security

- Include only owned tracked rebuild inputs and reject substituted archive payloads,
  recognizable credential material, unsafe paths, and unexpected root files.
- Keep PyPI publication opt-in and separate from GitHub Releases; preserve 1.0.0's
  explicit resource ownership and bounded cloud mutation contracts.

## Validation

Build provenance is available with the [GitHub release](https://github.com/Fuzzy-Technologies/F-Layer/releases/tag/v1.1.0).

## Breaking Changes

None. Version 1.1.0 adds packaging, documentation, and release checks to the 1.0.0
runtime contracts; existing `python -m flayer` commands remain supported.

## Try it from source

```bash
git clone https://github.com/Fuzzy-Technologies/F-Layer.git
cd F-Layer
git checkout v1.1.0
python -m pip install .
flayer --help
python -m flayer check --format json
```

Python 3.11 or newer is required. See the shipped user guide for an isolated
virtual environment and explicitly scoped cloud configuration.

## Notes

- Live cloud deployment, guest SSH/tunnel readiness, human translation approval,
  and actual PyPI publication are not claimed by these offline release checks.
- Install from the exact tag or attached wheel; a package-index upload is separate.
