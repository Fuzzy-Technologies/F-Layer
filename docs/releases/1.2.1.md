## Digest

F-Layer v1.2.1 makes the documentation easier to use: start with a practical
Quick Start, read clearer product descriptions, and follow verified Russian
and Chinese guides without translation-draft notices. Release publication now
requires a completed, closed milestone. Runtime and CLI behavior remain compatible
with 1.1.0 and the preliminary 1.2.0 snapshot.

## What's Changed

### Added

- Quick Start with installation, offline checks, help and first-deployment links
  in English, Russian and Simplified Chinese.
- The F-Layer company slide in the README and documentation landing pages,
  with a compact header logo and square favicon.
- Accountable AIna review of all 18 authored RU/ZH-CN pages, bound to the exact
  English source and translated text. Missing API translations remain English.

### Changed

- Describe the supported Yandex Cloud, secure SSH gateway and diagnostic workflows
  in language engineers and prospective customers can understand.
- Require a completed native release milestone before stable publication; use
  `F-Layer vX.Y.Z` titles and preserve published tags.
- Keep translation-review evidence in metadata rather than a notice on every
  approved page. AI reviews are identified explicitly and never called human approvals.

### Fixed

- Clipped landing-page slides and oversized header branding.
- Russian ownership wording, Chinese virtual-machine terminology, localized
  documentation links and consistent v1.2.1 installation examples.
- Translation drift checks now invalidate AI approval when the translated text
  changes, even if the English source stays unchanged.

## Breaking Changes

None for runtime APIs or CLI commands. Documentation review metadata now supports
explicitly authorized AI reviewers; human-only review remains the default.

## Try it from source

```bash
git clone https://github.com/Fuzzy-Technologies/F-Layer.git
cd F-Layer
git checkout v1.2.1
python -m pip install .
flayer --help
python -m flayer check --format json
```

Python 3.11 or newer is required. Package-index publication is a separate operation.
