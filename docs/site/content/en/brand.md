# Project identity

The overview and README use the project slide with **AIna** in the Fuzzy
Technologies engineering laboratory. The full-size source image is tracked as
`assets/brand/FTech-card-F-Layer.png`; its responsive presentation preserves
its aspect ratio on desktop and mobile.

![F-Layer with AIna in the Fuzzy Technologies engineering laboratory](assets/brand/FTech-card-F-Layer.png){ .fl-project-art }

The logo family follows FuzzyRoutines: a rounded dark frame, pale initial
letter and cyan/violet/pink spectrum. The horizontal wordmark is a compact
navigation logo in the top-left corner. The square **FL** sign remains the
browser favicon. The descriptor is **Infrastructure · Automation · Security**.

![F-Layer horizontal wordmark](assets/brand/flayer-horizontal.svg){ .fl-brand-lockup }

The SVG logos and CSS are tracked source assets. Site output and raster
previews of vector assets remain disposable; the supplied project slide is
an authored asset, not a generated build artifact.
