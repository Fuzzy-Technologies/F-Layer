# Project identity

F-Layer uses the same project-logo family as FuzzyRoutines: a thin rounded dark
frame, pale initial letter, monospaced wordmark and cyan/violet/pink spectrum.
The **FL** sign adds nested L-shaped lines to represent infrastructure layers.
The descriptor is **Infrastructure · Automation · Security**.

![F-Layer](assets/brand/flayer-horizontal.svg){ .fl-brand-lockup }

The source assets are accessible SVG vectors: the compact sign is used for
navigation/favicon, and the horizontal lockup introduces the project in the
README and overview. Theme colors keep the company's violet/green accents
without replacing the project sign's restrained spectrum. Generated raster
previews and HTML are disposable; edit the tracked SVG/CSS source instead.
