# Справочник API {#api-reference}

Здесь описаны модули Python из пакета F-Layer, для которого собрана эта
документация. Справочник создаётся из установленного wheel и сверяется
с исходниками: список модулей и параметры функций соответствуют этой версии
пакета.

Небольшой пример работы из Python есть в [руководстве по конфигурации](../guide/configuration.md).
[Обзор архитектуры](../architecture.md) объясняет, как связаны конфигурация,
провайдеры и управление развёртыванием.

Список модулей ниже формируется автоматически. Имена Python, параметры функций
и примеры кода сохраняют исходное написание на всех языках.
