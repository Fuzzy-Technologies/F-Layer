# Архитектура {#architecture}

F-Layer разделяет описание сервера, работу с облачным API и управление
развёртыванием. Так настройки проекта можно проверить без доступа к облаку,
а прерванную операцию — продолжить по сохранённому состоянию.
[Справочник API](api/index.md) описывает доступные модули этой версии.

| Компонент             | За что отвечает                                                                            |
| --------------------- | ------------------------------------------------------------------------------------------ |
| Конфигурация          | Проверяет параметры проекта и ресурсов. Пароли и токены в неё не входят.                   |
| Состояние             | Хранит ID ресурсов и результаты завершённых этапов развёртывания.                          |
| Провайдер             | Выполняет команды облачного API и проверяет, что ресурсы находятся в выбранном каталоге.   |
| Профиль развёртывания | Преобразует настройки сервера в план облачных ресурсов и файлы конфигурации.               |
| Жизненный цикл        | Создаёт, проверяет, восстанавливает и удаляет ресурсы; ведёт журнал операций.              |
| Диагностика           | Проверяет доступность и измеряет время запросов, исключая секреты из отчётов.              |
| Создаваемые файлы     | Хранят настройки сервера и клиентов, сведения о владельце и хеши для проверки целостности. |

В [описании архитектуры](../../../architecture/reference.md)
есть схемы взаимодействия компонентов и восстановления операций.
[Оглавление архитектуры](../../../architecture/README.md)
содержит подробные правила для каждого компонента, а
[ADR](../../../adr/README.md)
объясняют принятые решения и рассмотренные альтернативы. Новые провайдеры и
интеграции должны соблюдать эти границы и документировать свои особенности.

## Что проверяет сборка документации {#evidence-and-scope}

[Правила покрытия](../../../development/documentation-coverage.md)
определяют назначение каждого файла репозитория. Для публичных модулей создаётся
справочник API; тесты, инструменты и внутренние функции описываются отдельно.
Сборка сверяет содержимое установленного пакета с исходниками, проверяет ссылки
на определения API, переходы между страницами и доступность документации
из английского оглавления.

Примеры не содержат реальных учётных данных и состояния облачных ресурсов.
