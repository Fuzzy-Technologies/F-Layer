# Архитектура {#architecture}

F-Layer реализует конфигурацию и состояние, общие границы провайдеров, долговременный жизненный цикл и восстановление, преобразование операций Yandex с явной областью, артефакты защищённого шлюза и ограниченную диагностику. [Справочник установленного API](../en/api/index.md) перечисляет публичные контракты этой ревизии, включая исполняемый модуль CLI.

| Граница               | Ответственность                                                                                                   |
| --------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Конфигурация          | Проверять явные намерения и идентичность без встроенных учётных данных.                                           |
| Состояние             | Сохранять принадлежащие владельцу локаторы и зафиксированные свидетельства жизненного цикла.                      |
| Провайдер             | Преобразовывать облачные операции, проверять область и определять возможности.                                    |
| Профиль развёртывания | Компилировать результат инфраструктуры в независимые от провайдера планы и артефакты.                             |
| Жизненный цикл        | Журналировать намерения изменений, сверять наблюдения, сохранять состояние и восстанавливать прерванные операции. |
| Диагностика           | Формировать ограниченные свидетельства состояния и измерений с удалением чувствительных данных.                   |
| Создаваемые артефакты | Обеспечивать владение, происхождение и явные правила удаления.                                                    |

[Справочник реализованной архитектуры](https://github.com/Fuzzy-Technologies/F-Layer/blob/develop/docs/architecture/reference.md) содержит схемы композиции, восстановления и документации. [Оглавление архитектуры](https://github.com/Fuzzy-Technologies/F-Layer/blob/develop/docs/architecture/README.md) связывает устойчивые контракты; [оглавление ADR](https://github.com/Fuzzy-Technologies/F-Layer/blob/develop/docs/adr/README.md) перечисляет принятые решения и альтернативы. Будущим расширениям и интеграциям требуется собственный явный контракт.

## Свидетельства и область {#evidence-and-scope}

[Покрытие документации](https://github.com/Fuzzy-Technologies/F-Layer/blob/develop/docs/development/documentation-coverage.md) учитывает каждый отслеживаемый файл, не объявляя тесты, инструменты и частные вспомогательные функции потребительским API. Статическое обнаружение сверяет весь установленный пакет с исходниками. Перед публикацией проверяются якоря API, все канонические маршруты Markdown и достижимость из английской начальной страницы.

Учётные данные и реальное состояние ресурсов не становятся примерами документации.
