# Руководство пользователя {#user-guide}

Начните с локальной копии репозитория и явно выбранной области провайдера.
Базовый пакет проверяет конфигурацию, наблюдает ресурсы Yandex Cloud, выполняет
ограниченную диагностику, управляет инфраструктурой с явно заданным владением
и подготавливает защищённый SSH-шлюз. Руководство описывает требования к владению
и согласию на изменения до выполнения облачных операций.

1. [Установите из исходников](installation.md) и выполните проверку без сети.
2. [Настройте доступ к провайдеру](configuration.md) с заранее аутентифицированным профилем `yc`.
3. [Изучите результаты CLI](cli.md), включая неподдерживаемые наблюдения и коды завершения.
4. [Подготовьте первое развёртывание](first-deployment.md), явно задав владение и согласие на изменения.

Используйте точный стабильный тег, чтобы воспроизвести инструкции.
[Справочник API](../../en/api/index.md), построенный из установленного wheel,
описывает фактические модули этой ревизии.
