# Установка из исходников {#install-from-source}

F-Layer требует **Python 3.11 или новее** и Git. Дистрибутив `f-layer` содержит пакет Python `flayer`. Наличие опубликованного выпуска PyPI не предполагается: установите выбранные исходники, чтобы документация и поведение совпадали.

## Клонирование и установка {#clone-and-install}

```bash
git clone https://github.com/Fuzzy-Technologies/F-Layer.git
cd F-Layer
git checkout v1.1.0
python -m venv .venv
```

Активируйте среду для своей консоли:

| Консоль                  | Активация                    |
| ------------------------ | ---------------------------- |
| Linux/macOS bash или zsh | `source .venv/bin/activate`  |
| Windows PowerShell       | `.venv\Scripts\Activate.ps1` |
| Windows Command Prompt   | `.venv\Scripts\activate.bat` |

Установите и проверьте текущий пакет:

```bash
python -m pip install .
python -m flayer --help
python -m flayer check --format json
```

`check` проверяет локальную доступность среды и пакета. Он не аутентифицирует облачный аккаунт, не определяет папку, не создаёт инфраструктуру и не доказывает готовность гостевой системы. Успешная диагностика завершается кодом `0`.

В версии 1.1.0 команда модуля `python -m flayer` и установленная консольная
команда `flayer` принимают одинаковые аргументы. Переустанавливайте пакет
после переключения ревизии исходников.

## Среда для разработки {#development-checkout}

Участникам разработки следует установить редактируемые исходники и закреплённые инструменты проверки:

```bash
python -m pip install -e ".[dev]"
python tools/validate.py
```

Канонический запуск выполняет компиляцию, линтинг, проверку типов, все этапы тестов, проверяет отдельные пороги покрытия строк и ветвей и устанавливает wheel изолированно. Тесты используют синтетические ресурсы и запрещают незапрошенный сетевой доступ. Сборка документации описана в [процессе разработки](../development.md).

## Проблемы установки {#installation-issues}

| Признак                                      | Действие                                                                                                |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `No module named flayer`                     | Активируйте среду, использованную для `python -m pip install .`, и переустановите пакет из репозитория. |
| `python` недоступен                          | Последовательно используйте подходящий запуск Python 3.11+, например `python3` или `py -3.11`.          |
| `flayer` недоступен, команда модуля работает | Активируйте среду установки и переустановите 1.1.0; до этого используйте `python -m flayer`.            |
| Активация Windows заблокирована              | Для установки и команд используйте `.venv\Scripts\python.exe` напрямую.                                 |

Переустанавливайте пакет после смены ветки, чтобы он соответствовал исходной ревизии. Созданные среды, учётные данные и рабочее состояние не входят в отслеживаемые файлы.
