# Инфраструктура с явными контрактами {#infrastructure-with-explicit-contracts}

**F-Layer** — модульная платформа автоматизации для развёртывания, управления и интеграции защищённых облачных сред.

Архитектура разделяет конфигурацию, долговременное состояние ресурсов, возможности провайдеров, профили развёртывания, операции жизненного цикла и диагностические свидетельства. Эти границы позволяют заменять отдельные интеграции и воспроизводить операции.

## Принципы проектирования {#design-commitments}

- Ядро не зависит от облачного провайдера, сетевого протокола и приложения-потребителя.
- Учётные данные и частные идентификаторы инфраструктуры не входят в отслеживаемые исходники.
- Конфигурация, желаемое и наблюдаемое состояние, а также создаваемые артефакты разделены.
- Локальные проверки используют детерминированные фикстуры и не изменяют реальные облачные ресурсы.
- Аннотации Python и английские docstring служат источником истины для API.

[Руководство пользователя](guide/index.md) описывает работу в консоли, а [символика проекта](../en/brand.md) — семейство логотипов F-Layer.
