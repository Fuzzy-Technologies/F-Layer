# Развёртывайте облачные серверы и управляйте ими {#deploy-and-operate-cloud-servers}

**F-Layer** помогает инженерам разворачивать серверы в облаке, управлять
ресурсами своего сервиса и проверять его доступность. Им можно пользоваться
из командной строки или встраивать его Python API в своё приложение.

Опишите развёртывание в файле конфигурации. F-Layer подготовит план ресурсов,
создаст их после вашего явного разрешения и сохранит локальный список
идентификаторов. С тем же планом и списком можно проверить состояние сервера,
восстановить прерванную операцию или удалить ресурсы этого развёртывания.

Сейчас доступны **Yandex Cloud**, **защищённый SSH-шлюз** с настройками
подключения для отдельных устройств, проверка HTTP-сервисов и измерение
времени отклика и передачи данных. Это инструмент для команд, которые
автоматизируют инфраструктуру сервисов, и разработчиков, добавляющих такие
возможности в свои продукты. Другие облака и VPN-профили — в планах.
F-Layer открыт и бесплатен; облачные ресурсы оплачиваются вашему провайдеру.

## Быстрый старт {#quick-start}

[Установите готовый пакет](guide/installation.md), затем перейдите к
[быстрому старту](guide/index.md) с примером для Yandex Cloud.
После установки эта команда работает без доступа к облаку:

```bash
python -m flayer check --format json
```

Ожидаемый результат: `"status": "ok"` и код завершения `0`. Это проверка
локального Python и пакета. Для создания сервера переходите к инструкции
по развёртыванию.
