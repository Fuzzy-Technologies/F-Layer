# 架构 {#architecture}

F-Layer 已实现配置和状态、通用云提供方接口、持久化生命周期管理与恢复、限定作用域的 Yandex 云操作适配、安全网关制品和有界诊断。[已安装 API 参考](api/index.md)列出此版本中的公开契约，包括可执行 CLI 模块。

| 边界         | 职责                                                           |
| ------------ | -------------------------------------------------------------- |
| 配置         | 验证明确的用户意图和身份，不嵌入凭据。                         |
| 状态         | 保留归属明确的资源标识和已提交的生命周期证据。                 |
| 提供方       | 将通用操作转换为云平台操作，并负责作用域验证和能力发现。       |
| 部署配置方案 | 将期望的基础设施配置编译为不依赖具体云提供方的计划和制品。     |
| 生命周期     | 记录变更意图、核对观测、持久化状态并恢复中断操作。             |
| 诊断         | 在限定时间和数据量内执行健康检查与性能测量，输出脱敏后的结果。 |
| 生成的制品   | 校验资源归属和来源，并要求按明确规则删除。                     |

[已实现架构参考](../../../architecture/reference.md)包含组合、恢复和文档图示。[架构目录](../../../architecture/README.md)链接各稳定契约；[ADR 目录](../../../adr/README.md)记录已接受决策和替代方案。未来扩展和集成行为需要自己的明确契约。
