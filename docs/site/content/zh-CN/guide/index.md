# 用户指南 {#user-guide}

从本地仓库和明确的提供方作用域开始。基础包可以验证配置、查看 Yandex Cloud
资源、运行有界诊断、管理明确归属的基础设施，并准备安全 SSH 网关。
操作说明会在任何云操作之前说明所有权和变更许可要求。

1. [从源码安装](installation.md)，执行离线冒烟检查。
2. 使用已认证的 `yc` 配置档[配置提供方访问](configuration.md)。
3. [阅读 CLI 结果](cli.md)，包括不支持的观测和退出码。
4. 明确指定所有权和变更许可，[准备首次部署](first-deployment.md)。

请使用明确的稳定 Git 标签来复现说明。由已安装 wheel 生成的
[API 参考](../../en/api/index.md)描述此版本中实际存在的模块。
